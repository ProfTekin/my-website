REFERENCE 02 / CSS

CSS: make it feel right.

Shape a readable, consistent design. Change values, observe the result, and understand the rule behind it.

One stylesheet, every page

CSS describes presentation. Link the same stylesheet in every page’s head so shared design stays consistent.

Code
/* style.css */
:root { --accent: #315bdb; }
body { font-family: system-ui, sans-serif; color: #1c2636; }
h1 { color: var(--accent); }
.card { background: white; padding: 1.5rem; }

A rule has a selector and a block of property: value declarations. End each declaration with a semicolon. In HTML use <link rel="stylesheet" href="style.css">. External stylesheets avoid repeating style rules in every page.

Selectors: elements, classes and IDs

Select all elements of a type, reusable groups, or one unique element.

Code
p { line-height: 1.6; }
.product { border: 1px solid #ccd5e0; }
#special-offer { background: #edf2ff; }
.product a { color: #315bdb; }

p selects paragraphs, .product selects a class, and #special-offer selects an ID. The last rule selects links inside a product. In ordinary rules, specificity and source order help decide which declaration wins. Avoid unnecessary ID styling when reusable classes will do.

Typography, colors and units

Choose readable text and sufficient contrast. Use a few consistent sizes.

Code
body { font-size: 1rem; line-height: 1.6; }
h1 { font-size: clamp(2rem, 5vw, 4rem); }
.intro { max-width: 65ch; }
.banner { color: #ffffff; background-color: #254cbb; }
.logo { width: 80%; max-width: 20rem; }

rem relates to the root font size, em often relates to an element’s font size, px is a CSS pixel, % depends on the property and containing context, vw is a percentage of viewport width, and ch roughly measures the width of the zero glyph. clamp sets a minimum, flexible preferred value and maximum.

Color playground

Compare foreground and background colors. The ratio is calculated from relative luminance. Aim for at least 4.5:1 for ordinary text; 3:1 applies to large text. Color alone should not communicate meaning.

The box model

Every box has content, padding, border and margin. Padding creates space inside the border; margin separates a box from nearby elements.

Code
* { box-sizing: border-box; }
.card {
  width: 100%;
  max-width: 30rem;
  min-height: 8rem;
  padding: 20px;
  border: 5px solid #507bc1;
  margin: 20px;
}

With border-box, the stated width includes padding and border, but not margin. Fixed heights can clip content, so use natural height or min-height where possible.

Display, sizing and positioning

Block boxes usually start on a new line. Inline content flows with text. Flex and grid create layout systems.

Code
.hidden { display: none; }
.badge { display: inline-block; padding: 0.3rem; }
.card { position: relative; }
.card .label { position: absolute; top: 1rem; right: 1rem; }
.sidebar { position: sticky; top: 1rem; }

display: none removes an element from layout and the accessibility tree. relative keeps normal-flow space; absolute positions against its containing block, often the nearest positioned ancestor. fixed is usually viewport-relative. sticky follows scrolling within its scrolling context and containing block. Use normal layout before reaching for positioning.

CSS Grid: rows and columns

Grid is useful for page regions and two-dimensional collections such as product cards.

Code
.products {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
}
@media (max-width: 600px) {
  .products { grid-template-columns: 1fr; }
}

1fr shares remaining space. minmax(0, 1fr) allows tracks to shrink below their content’s minimum width. gap separates cells. At 600px or narrower, this layout becomes one column.

Try it yourself

Change three columns to two. Then try repeat(auto-fit, minmax(12rem, 1fr)).

Responsive design and media queries

Let content fit its available space. Avoid assuming everyone uses the same screen or input device.

Code
img { max-width: 100%; height: auto; }
.container { width: min(100% - 2rem, 70rem); margin: auto; }
.cards { display: grid; grid-template-columns: repeat(3, 1fr); }
@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
}

The media query responds to viewport width, not the type or brand of device. Keep the viewport meta tag in the HTML head. Test long text, zoom, portrait orientation and keyboard navigation.

Variables, reusable styles and transitions

Custom properties keep repeated values consistent. Reuse a class for components that share a purpose.

Code
:root { --brand: #315bdb; --space: 1rem; }
.button {
  background: var(--brand);
  padding: var(--space);
  border-radius: 8px;
  transition: background-color 150ms ease;
}
.button:hover, .button:focus-visible { background: #21409c; }
@media (prefers-reduced-motion: reduce) {
  .button { transition: none; }
}

Variables participate in the cascade. Transitions animate a change between property values; they do not create the change. Avoid animating everything, and respect reduced-motion preferences.
