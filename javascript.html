Load script.js and understand defer

The browser reads your HTML and creates a document model. An external script can then find and change those elements.

Code
<!-- In the head of each HTML file -->
<script src="script.js" defer></script>

src names the JavaScript file. defer lets the browser download a classic external script while parsing HTML and execute it after parsing finishes, before DOMContentLoaded. Without it, a script in the head may look for elements that do not yet exist. Do not put HTML tags inside script.js.

Variables, values and types

Variables give names to values. const prevents reassignment of that binding; let allows reassignment.

Code
const caféName = "Alpine Coffee"; // string
const price = 3.5;               // number
let quantity = 2;
const available = true;          // boolean
quantity = 3;
const total = price * quantity;
console.log(caféName, total, available);

Strings use quotes. Numbers support arithmetic. Booleans are true or false. const does not make the contents of an object or array immutable. Prefer clear names. Input.value is a string, even for a number input; convert it before arithmetic.

Try it yourself

Predict total, then change quantity and check with console.log().

Functions and parameters

A function groups instructions you can run again. Parameters are names for values supplied to a call.

Code
function calculateTotal(price, quantity) {
  return price * quantity;
}
const total = calculateTotal(3.5, 2);
console.log(total); // 7

price and quantity are parameters. 3.5 and 2 are arguments in this call. return supplies the result to the caller. Defining a function does not call it.

Try it yourself

Conditions and comparisons

Use a condition to choose what to do. A comparison produces a boolean.

Code
const quantity = 3;
if (quantity >= 5) {
  console.log("Group order");
} else {
  console.log("Small order");
}
console.log(quantity === 3); // true
console.log(quantity !== 3); // false

Use === for strict equality and !== for inequality. >, <, >= and <= compare values. = assigns a value. && means both conditions, || means at least one, and ! negates. Avoid confusing assignment with comparison.

Arrays and loops

An array keeps a list of values. Loops repeat work for each item.

Code
const drinks = ["Espresso", "Tea", "Cocoa"];
console.log(drinks[0]); // Espresso: indexes start at 0
for (const drink of drinks) {
  console.log(drink);
}
for (let i = 0; i < drinks.length; i++) {
  console.log(i, drinks[i]);
}

length is the number of items. The first loop visits each value. The second uses an index, continuing while the condition is true. i++ increases i by one.

The DOM and selectors

The Document Object Model represents your page as nodes and elements. JavaScript can select elements using IDs or CSS selectors.

Code
const heading = document.getElementById("welcome");
const firstCard = document.querySelector(".product");
const allCards = document.querySelectorAll(".product");
heading.textContent = "Welcome to our café";
for (const card of allCards) {
  card.classList.add("featured");
}

getElementById takes the ID without #. querySelector returns the first match; querySelectorAll returns a collection. A single selector with no match returns null. textContent changes plain text. Avoid inserting untrusted content with innerHTML: it parses markup and can introduce security problems. Prefer textContent when changing text. Related: HTML IDs and classes.

Events: onclick and addEventListener

An event is something that happens, such as click, input or submit. Register a function to respond.

Code
const button = document.getElementById("welcome-button");
function greet() {
  console.log("Hello!");
}
button.addEventListener("click", greet);
// Alternative: button.onclick = greet;
// Use one approach here, not both. Inline onclick attributes exist,
// but keeping handlers in script.js separates structure and behavior.

Pass greet, not greet(), so the function runs on the event rather than immediately. onclick stores one handler; addEventListener can register multiple independent listeners. A real button also supports keyboard activation.

03 · Toggle a design class

Objective: use a CSS class to change a whole region’s appearance.

index.html · inside body
<button type="button" id="theme" aria-pressed="false">Dark mode</button>
<p>The same content, a different theme.</p>
script.js
const button = document.getElementById("theme");
button.addEventListener("click", function () {
  const isDark = document.body.classList.toggle("dark");
  button.setAttribute("aria-pressed", String(isDark));
});
style.css · feature styles
body.dark { background: #172233; color: #f4f7fc; }

classList.toggle adds a class if absent and removes it if present. The CSS does the visual work. aria-pressed tells assistive technology whether the toggle is active.

04 · Image gallery

Objective: change an image source and its alternative text together.

index.html · inside body
<img id="photo" src="../../images/coffee.svg" alt="A steaming coffee cup" width="200" height="150">
<div><button id="next" type="button">Next image</button></div>
<p id="caption" aria-live="polite">Coffee · 1 of 3</p>
script.js
const images = [
  {src: "../../images/coffee.svg", alt: "A steaming coffee cup", name: "Coffee"},
  {src: "../../images/mountains.svg", alt: "Layers of Alpine peaks", name: "Mountains"},
  {src: "../../images/pastry.svg", alt: "A golden croissant", name: "Pastry"}
];
let index = 0;
const photo = document.getElementById("photo");
const caption = document.getElementById("caption");
document.getElementById("next").addEventListener("click", function () {
  index = (index + 1) % images.length;
  photo.src = images[index].src;
  photo.alt = images[index].alt;
  caption.textContent = images[index].name + " · " + (index + 1) + " of 3";
});
style.css · feature styles
img { display: block; object-fit: cover; margin-bottom: 10px; }

The array stores objects with matching paths, descriptions and captions. % wraps the index back to zero. Updating alt ensures the new image still has a correct description.

05 · FAQ accordion

Objective: show and hide an answer while keeping its state accessible.

index.html · inside body
<button type="button" id="question" aria-expanded="false" aria-controls="answer">Do you offer plant-based milk?</button>
<p id="answer" hidden>Yes. Ask about our oat drink option.</p>
script.js
const question = document.getElementById("question");
const answer = document.getElementById("answer");
question.addEventListener("click", function () {
  answer.hidden = !answer.hidden;
  question.setAttribute("aria-expanded", String(!answer.hidden));
});

hidden controls visibility. ! reverses a boolean. aria-controls links the button to the answer; aria-expanded reports its state. Native details/summary is another useful option when custom JavaScript is unnecessary.

06 · Product filter

Objective: compare a selected category with each product’s data attribute.

index.html · inside body
<label for="category">Show products</label>
<select id="category"><option value="all">All</option><option value="drink">Drinks</option><option value="food">Food</option></select>
<ul><li class="product" data-category="drink">Espresso</li>
<li class="product" data-category="drink">Tea</li>
<li class="product" data-category="food">Croissant</li></ul>
<p id="count" role="status">3 products shown</p>
script.js
const category = document.getElementById("category");
const products = document.querySelectorAll(".product");
category.addEventListener("change", function () {
  let count = 0;
  for (const product of products) {
    product.hidden = category.value !== "all" &&
      product.dataset.category !== category.value;
    if (!product.hidden) count++;
  }
  document.getElementById("count").textContent = count + " products shown";
});

change fires when the choice changes. dataset.category reads data-category. A product is hidden only when the selection is not all and its category does not match.

07 · Price calculator

Objective: read and validate input before calculating a total.

index.html · inside body
<label for="quantity">Coffee quantity (€3.50 each)</label>
<input type="number" id="quantity" min="1" max="20" step="1" value="1">
<button type="button" id="calculate">Calculate</button>
<p id="total" role="status">Choose a quantity.</p>
script.js
const quantity = document.getElementById("quantity");
const total = document.getElementById("total");
document.getElementById("calculate").addEventListener("click", function () {
  const number = Number(quantity.value);
  if (!Number.isInteger(number) || number < 1 || number > 20) {
    total.textContent = "Enter a whole number from 1 to 20.";
    return;
  }
  total.textContent = "Total: €" + (number * 3.5).toFixed(2);
});
style.css · feature styles
input { width: 70px; margin: 8px; }

Number converts the string from value. Number.isInteger and range checks reject unsuitable values. return ends the handler early for invalid input. toFixed(2) formats two decimal places. This is a demonstration, not a payment system.

08 · Responsive navigation

Objective: toggle a compact menu and keep it visible on larger viewports. Resize the standalone example to test both layouts.

index.html · inside body
<button type="button" id="menu-button" aria-expanded="false" aria-controls="links">Menu</button>
<nav id="links" aria-label="Demo navigation">
  <a href="#home">Home</a><a href="#about">About</a>
</nav>
<h2 id="home">Home</h2><p id="about">A fictional café demo.</p>
script.js
const button = document.getElementById("menu-button");
const links = document.getElementById("links");
button.addEventListener("click", function () {
  const open = links.classList.toggle("open");
  button.setAttribute("aria-expanded", String(open));
});
document.addEventListener("keydown", function (event) {
  if (event.key === "Escape") {
    links.classList.remove("open");
    button.setAttribute("aria-expanded", "false");
    button.focus();
  }
});
style.css · feature styles
nav { display: flex; gap: 16px; }
#menu-button { display: none; }
@media (max-width: 600px) {
  #menu-button { display: inline-block; }
  nav { display: none; }
  nav.open { display: flex; }
}

CSS handles the breakpoint; JavaScript toggles the open class. The button exposes expanded state and Escape closes the compact menu. Links remain normal navigation links.

Basic form validation

Use built-in constraints and prevent submission in a local demonstration. Validation in a browser helps usability; it is not a security boundary for a real server.

Code
// Use with the form shown on the HTML reference page.
const form = document.getElementById("demo-form");
form.addEventListener("submit", function (event) {
  event.preventDefault();
  document.getElementById("feedback").textContent =
    "Format accepted. Nothing was sent or saved.";
});

The browser checks required and type=email before a normal submit event. preventDefault stops navigation/submission. A real service would require an approved backend and server-side validation; this project does not require one.
