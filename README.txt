PACKET LAB

Open index.html in any modern browser. No installation, server, external fonts or internet connection is required for the lessons and simulations. External further-reading links require internet.

Files: index.html, layers.html, security.html, style.css, script.js, images/ (original SVG illustrations). Keep the folder together. HTML supplies structure, CSS controls appearance, JavaScript handles interactions.

Recommended teaching sequence: Connect (hardware and topology experiments); Communicate (protocols, OSI journey, connection decisions and operating systems); Protect (architecture, firewall policy and school-network design).

Simulations simplify real networks. Notes and checkpoint completion stay in the current browser where local storage is available. Download notes for submission. No data is sent to a server by the lessons. Local-file browser storage behaviour can vary.

To publish as a static website, upload the contents of my_website with index.html at the site root.
