Example: A Complete Company Website

Alpine Coffee is a fictional café in Innsbruck. Explore all four pages, try the menu filter and calculator, and open the FAQ. It is a learning reference, not a project to copy and submit unchanged.

Each page links to the other three by filename. All four load the same style.css and script.js. Every image path starts with images/ because the images folder sits next to these HTML pages. Copy the complete alpine-coffee folder to keep it standalone; the “Back to handbook” link needs the handbook alongside it.

The CSS uses Grid for product cards and a media query at 700px to switch to one column. It also changes the navigation into a button-controlled menu. Images scale within their containers.

The JavaScript checks whether each page-specific control exists before attaching its listener. This lets the same script run on all four pages without trying to use missing elements. The filter compares data-category values; the calculator validates quantity before multiplication; FAQ buttons update hidden and aria-expanded.

Complete script.js
alpine-coffee/script.js
// Shared script: check that page-specific controls exist before using them.
const menuButton = document.getElementById('menu-button');
const navigation = document.getElementById('navigation');
menuButton.addEventListener('click', function () {
  const open = navigation.classList.toggle('open');
  menuButton.setAttribute('aria-expanded', String(open));
});
document.addEventListener('keydown', function (event) {
  if (event.key === 'Escape' && navigation.classList.contains('open')) {
    navigation.classList.remove('open');
    menuButton.setAttribute('aria-expanded', 'false');
    menuButton.focus();
  }
});
const category = document.getElementById('category');
if (category) {
  category.addEventListener('change', function () {
    let count = 0;
    for (const product of document.querySelectorAll('.product')) {
      product.hidden = category.value !== 'all' && product.dataset.category !== category.value;
      if (!product.hidden) count++;
    }
    document.getElementById('product-count').textContent = count + ' items shown';
  });
}
const calculate = document.getElementById('calculate');
if (calculate) {
  calculate.addEventListener('click', function () {
    const quantity = Number(document.getElementById('quantity').value);
    const price = Number(document.getElementById('drink').value);
    const total = document.getElementById('total');
    if (!Number.isInteger(quantity) || quantity < 1 || quantity > 20) {
      total.textContent = 'Choose a whole quantity from 1 to 20.';
      return;
    }
    total.textContent = 'Illustrative total: €' + (price * quantity).toFixed(2) + '. No order has been placed.';
  });
}
for (const question of document.querySelectorAll('.question')) {
  question.addEventListener('click', function () {
    const answer = document.getElementById(question.getAttribute('aria-controls'));
    answer.hidden = !answer.hidden;
    question.setAttribute('aria-expanded', String(!answer.hidden));
  });
}

Try it yourself

Trace one click from its HTML button to its event listener, then to the visible result. Explain it to your partner without reading the explanation above.

Learn from the pattern

  • Identify the purpose of each page before choosing a visual design.
  • Create your own business content and multimedia.
  • Use a feature only when it helps your audience.
  • Document sources, test small screens and explain your code.
The fictional company has no real contact details, form submission, payments or booking system. Those are deliberate prototype boundaries.
