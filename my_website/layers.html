02.1 / SHARED RULES

Three jobs. Three protocols.

A protocol is a set of rules for communication: what messages mean, how they are formatted and how devices respond.

IP

Address & route

The Internet Protocol provides addressing and carries packets across interconnected networks. Delivery is best-effort: packets can be lost, duplicated or arrive out of order.

192.168.1.25 · IPv4

IPv4 uses 32-bit addresses; IPv6 uses 128-bit addresses. An IP address identifies a network interface in context.

TCP

Reliable byte stream

The Transmission Control Protocol runs over IP. It uses sequence numbers, acknowledgements and retransmission to provide an ordered byte stream, or reports a connection failure.

SYN → SYN-ACK → ACK

Ports identify application endpoints. TCP also manages flow and congestion. Reliability does not mean encryption.

FTP

Transfer files

The File Transfer Protocol is an application protocol that transfers files over TCP. It uses separate control and data connections.

Application → TCP → IP

Classic FTP sends credentials and data without encryption. FTPS adds TLS; SFTP is a different protocol over SSH.

02.2 / ISO–OSI REFERENCE MODEL

One journey.
Seven layers.

The Open Systems Interconnection model is a conceptual framework. Real internet implementations use the TCP/IP suite; not every function maps neatly to one OSI layer.

Select any layer to investigate it.

Encapsulation adds control information on the way down; decapsulation removes it on the way up. Switches and routers generally process only the lower layers for forwarding.

02.4 / THE SOFTWARE FOUNDATION

Different systems.
Same shared protocols.

An operating system manages hardware, applications, files, users and network access. Devices can communicate even when they run different operating systems.

Windows

Common on school and office PCs. Supports user accounts, file sharing, device drivers and a built-in networking stack. Windows Server is a separate server product.

macOS

Apple’s desktop operating system. Offers a graphical interface and Unix foundations, with network tools and file sharing.

GNU/Linux

A family of distributions such as Ubuntu and Debian. Used on desktops, servers and embedded systems. Many components are open source.

Android & iOS / iPadOS

Mobile operating systems with app permission controls and support for Wi-Fi, Bluetooth and, on equipped devices, cellular data.
